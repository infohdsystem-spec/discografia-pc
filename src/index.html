        Bienvenido a Discografía

        Versión 8.0.0 · Stable Release

        Discografía v8.0.0 es una aplicación web autocontenida para catalogar, organizar, enriquecer y analizar tu colección.

        🎉
        ¡Stable Release! Después de un extenso desarrollo (v7.1.0 → v8.0.0), esta versión consolida todas las funcionalidades: multi-colección, i18n, etiquetas, filtros guardados, command palette, etiquetas imprimibles y más.
        ⚠️
        IMPORTANTE: la app debe ejecutarse desde un servidor local, no con doble clic en el HTML. Usá INICIAR.bat (Windows) o INICIAR.sh (Linux/Mac).
        📚

        Multi-colección (Workspaces)

        Desde la v7.8.0 podés gestionar varias colecciones independientes. Cada una tiene su propia base de datos (IndexedDB + localStorage).

        Cómo usar

        1. En el header, al lado del logo, aparece un selector con el nombre de la colección actual.
        2. Hacé clic para ver todas tus colecciones.
        3. Cambiá de colección con un clic (la app se recarga).
        4. Creá, renombrá, personalizá o eliminá con los botones en cada fila.

        Casos de uso

        • Colección personal + colección de vinilos + colección de CDs de papá
        • Colección activa + colección vendida + wishlist
        • Colección propia + colección para tasación de un cliente
        🌎

        Idiomas

        La app soporta 3 idiomas: Español (es-AR), English (en-US), Português (pt-BR).

        Cambialo desde ⚙️ → 🌎 Idioma. El idioma se guarda y se mantiene entre sesiones.

        Los números, fechas y monedas se formatean según el idioma elegido (1.234,56 en español, 1,234.56 en inglés).

        🏷️

        Etiquetas (Tags)

        Cada CD puede tener hasta 12 etiquetas libres. Son útiles para clasificaciones que no encajan en las categorías.

        Ejemplos

        favorito, para_vender, regalo, autografiado, edicion_limitada, para_digitalizar

        Cómo usarlas

        1. Abrí un CD → pestaña 🏷️ Etiquetas → escribí y presioná Enter
        2. Filtrá por etiqueta: botón 🏷️ en la toolbar
        3. Búsqueda avanzada: tag:rock, tag:favorito regalo
        4. Gestión global: botón 🏷️ → ⚙️ Gestionar etiquetas
        💾

        Filtros guardados

        Guardá combinaciones de filtros (búsqueda + filtros + categoría + ordenamiento) con un nombre e ícono y aplicalas con un clic.

        Cómo usar

        1. Aplicá algún filtro, búsqueda o seleccioná una categoría
        2. Clic en 💾 en la toolbar
        3. Guardar filtros actuales → ponele nombre e ícono
        4. Aparecerá en la lista para aplicar con un clic

        Máximo: 30 filtros guardados.

        ⌘

        Command Palette

        Ctrl+Shift+K abre la paleta de comandos con búsqueda fuzzy.

        Accedé a TODAS las acciones sin mouse:

        • Nuevo CD, nueva categoría, dashboard, grid…
        • Exportar JSON/CSV/PDF
        • Ir a cualquier categoría
        • Aplicar cualquier filtro guardado
        • Cambiar tema, idioma, colección
        • Gestionar etiquetas, duplicados, préstamos

        Navegá con ↑↓ y ejecutá con Enter.

        📲

        Modo offline (PWA)

        Desde v7.2.0 la app funciona sin internet después de la primera carga.

        ✅ Qué funciona offline

        • Ver, crear y editar CDs
        • Buscar, filtrar, etiquetar
        • Ver portadas ya cargadas
        • Exportar JSON/CSV/PDF

        ❌ Qué NO funciona offline

        • Enriquecimiento (necesita APIs)
        • Resolver links de streaming
        • Cargar portadas nuevas
        🌐

        Servidor local

        Si abrís la app con doble clic, el navegador usa origin: null y bloquea las APIs. Usá INICIAR.bat (Windows) o INICIAR.sh (Linux/Mac).

        💾

        Almacenamiento

        La base de datos vive en IndexedDB con fallback a localStorage. Cada workspace tiene su propia DB.

        Migración automática: si tenías datos en localStorage, se migran solos la primera vez.

        🎵

        Configurar Last.fm

        1. Andá a last.fm/api/account/create
        2. Completá el formulario (es instantáneo)
        3. Copiá la API key (32 caracteres hex)
        4. En la app: ⚙️ → 🎵 Configurar Last.fm
        📂

        Subcategorías

        Organizá cada categoría en subcategorías.

        🎧

        Streaming inteligente

        Desde la vista de un CD aparece la sección 🎧 Escuchar en.

        ✅
        100% legal: NO descarga audio.
        ⚖️

        Aviso legal + Firma SHA-256

        La primera vez aparece un modal con el aviso legal.
